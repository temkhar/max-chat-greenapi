# Прототип мессенджера MAX Chat (Интеграция с GREEN-API)

Веб-приложение представляет собой функциональный прототип мессенджера, визуально повторяющий интерфейс веб-версии Telegram/MAX, с возможностью авторизации, создания диалогов, а также отправки и получения текстовых сообщений в реальном времени через API-шлюз **GREEN-API**.

## 🛠️ Стек технологий

*   **Фронтенд-фреймворк:** React 19 (строгая типизация TypeScript)
*   **Сборщик проекта:** Vite 5+
*   **Стилизация интерфейса:** Tailwind CSS v4 (с использованием компилятора Lightning CSS и конфигурации `@theme` внутри CSS-слоя)
*   **HTTP-клиент:** Axios (для асинхронных запросов к шлюзу)
*   **Иконки:** Lucide-React

## ⚙️ Функционал приложения

1.  **Авторизация (Вход по ключам):** Пользователь вводит свои `idInstance` и `apiTokenInstance`. Данные валидируются и сохраняются в `localStorage`, что предотвращает сброс сессии при перезагрузке страницы.
2.  **Управление диалогами:** Возможность добавления нового собеседника по полному номеру телефона через модальное окно. Автоматическое создание чата при получении сообщения от нового контакта.
3.  **Отправка сообщений (SendMessage):** Интерактивное поле ввода с кнопкой-самолётиком. Поддерживает отправку как по клику, так и по нажатию клавиши `Enter`.
4.  **Служба входящих сообщений (Long Polling):** Реализован непрерывный фоновый цикл опроса методов `ReceiveNotification` и `DeleteNotification` с автоматической очисткой очереди на сервере шлюза для предотвращения зацикливания.
5.  **Удобство интерфейса (UX):** Реализован плавный автоматический скролл к последнему сообщению при открытии диалога или получении новой реплики.

## 🚀 Инструкция по локальному развертыванию

### 1. Установка зависимостей
Склонируйте репозиторий, перейдите в корень проекта и установите все необходимые пакеты:
```bash
npm install
```

### 2. Запуск в режиме разработки
Для запуска локального сервера разработки выполните:
```bash
npm run dev
```
После запуска откройте в браузере адрес: `http://localhost:5173/`

### 3. Сборка продакшн-версии (Production Build)
Для компиляции оптимизированного, сжатого и минифицированного бандла выполните команду:
```bash
npm run build
```
Готовые файлы для выкатки на хостинг будут сгенерированы в папке `dist/`.

### 4. Проверка продакшн-версии локально
Для тестирования собранного бандла из папки `dist` используйте команду:
```bash
npm run preview
```

## 🔍 Особенности интеграции с WhatsApp

*   **Форматирование номеров:** Приложение автоматически очищает вводимые номера телефонов от пробелов, дефисов и знаков `+` с помощью регулярных выражений, приводя их к валидному для WhatsApp ID формату `номер@c.us`.
*   **Очередь уведомлений:** Проект строго следует спецификации GREEN-API: после успешного парсинга вебхука приложение отправляет запрос на удаление события из очереди, обеспечивая стабильное продвижение стека сообщений.
